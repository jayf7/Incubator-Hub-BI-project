# Incubator-Hub-BI-project
An interactive business financial performance analysis dashboard developed using Micorosft Power BI

## Project Overview

This project focuses on analysing business financial performance using Microsoft Power BI.

The aim is to transform raw business data into meaningful insights that support financial monitoring, performance evaluation and better business decision-making.

Through an interactive dashboard, this project explores profitability, branch performance, operating expenses and overall financial health.

## Project Objectives

The key objectives of this project are to:

- Analyse overall financial performance.
- Evaluate Operating Profit and Net Profit.
- Compare financial performance across business branches.
- Identify areas of financial loss and operational challenges.
- Analyse expenses and operational performance.
- Present findings through interactive visualisations.
- Support data-driven business decisions.

## Dashboard Pages

The report consists of the following pages:

1. **Overview:** Provides a summary of the organisation's financial performance and key performance indicators.

2. **Profit & Loss:** Examines revenue, expenses, Operating Profit and Net Profit.

3. **Expense & Operational Analysis:** Explores business expenses and operational performance.

4. **Management Summary:** Presents key financial information to support management review and decision-making.

## Key Areas of Analysis

- Operating Profit and Net Profit
- Branch Financial Performance
- Profitability Analysis
- Expense Analysis

## Key Insights

This section highlights the findings identified during the analysis.

- Identification of branches experiencing financial losses.
- Evaluation of negative Operating Profit and Net Profit.
- Comparison of financial performance across branches.
- Identification of expense and operational areas requiring attention.

## Business Recommendations

Based on the findings, management can:

- Investigate branches recording significant financial losses.
- Review operating expenses and identify opportunities for cost reduction.
- Monitor profitability across business branches.
- Use financial performance indicators to support strategic decisions.
